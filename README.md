# msh (Modi Shell) - CodeMate Hackathon Project



A Python-based command-line tool built for the CodeMate Hackathon. It features core file system operations, a system dashboard, and a simulated AI assistant.



## Features Implemented

- Standard file/directory commands: `ls`, `cd`, `pwd`, `mkdir`, `rm`

- System monitoring: `dashboard` for live CPU and Memory usage.

- AI Assistant: `modi` command for natural language queries.

- Help command: `help` to list all available commands.



## How to Run

1. Ensure you have Python installed on your system.

2. Open a terminal or command prompt.

3. Navigate to the project directory.

4. Run the script with the command: `python main.py`
